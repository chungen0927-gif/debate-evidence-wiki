# 辯論的資料使用 LLM Wiki

給剛入社的高中社員：辯論要怎麼找資料、看資料、用資料。這是我（演辯社社課講師）用 Karpathy 式 LLM Wiki 的做法建的知識庫，再用它生成一份教學簡報。

- 教學簡報：https://chungen0927-gif.github.io/debate-evidence-wiki/slides/
- Wiki 目錄：[wiki/index.md](wiki/index.md)
- 規則手冊：[AGENTS.md](AGENTS.md)
- 工作紀錄（收錄、健檢、生成的過程）：[wiki/log.md](wiki/log.md)

## 結構

```
AGENTS.md   規則手冊（AI 先訪談我，再寫成這份）
raw/        原始資料 8 篇（網路文章只放來源資訊和短摘錄）
wiki/       AI 整理的知識頁：sources/ 來源頁、concepts/ 概念頁、examples/ 範例頁
slides/     從 Wiki 生成的教學簡報、簡報大綱
```
